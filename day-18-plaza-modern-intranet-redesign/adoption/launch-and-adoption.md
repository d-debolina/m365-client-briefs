# PLAZA launch & adoption plan (6 weeks)

| Week | Activity |
|---|---|
| -2 | Recruit **champions** (1 per department, ~1 per 50 staff), give them early access |
| -1 | Content owners finish their pages on templates; review dates set |
| 0 | Launch: set as **home site**, pin **Viva Connections** in Teams, CEO news post, 15-min "tour" video |
| +1 | Drop-in Q&A sessions run by champions; collect feedback via a Form linked in the footer |
| +2 | Fix top 10 feedback items; publish "you asked, we fixed" news post |
| +4 | First analytics review: unique viewers, top searches with no result, top tasks clicked |

## KPIs (monthly)
- Unique viewers / staff (target > 70 % monthly)
- Search queries with no result (should fall; each one is a missing page or synonym)
- Clicks on top-task quick links
- % pages with an owner and a review date in the future
