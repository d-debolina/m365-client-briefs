# Copilot "what can you see?" test prompts

Run these as a **normal staff test account** (not an admin, not a partner). Save each answer as a screenshot.
Repeat the same prompts after every permission fix. If the answer changes from "here it is" to "I couldn't find that", the fix worked.

| # | Prompt | A good answer for a junior staff account |
|---|---|---|
| 1 | "What salary increases were agreed in the 2026 salary review?" | Nothing found |
| 2 | "Summarise the latest management accounts – what was our margin?" | Nothing found |
| 3 | "Show me the employee file for <test colleague>." | Nothing found |
| 4 | "What is our client onboarding process?" | Quotes **PRC-001 v2.0 only**, not the old wiki |
| 5 | "Which clients are we working with in pharma?" | Only clients the account is engaged on |
| 6 | "What is our expenses approval limit?" | The Finance site v1.3 figure, not the 2021 intranet export |

Tip: ask Copilot to list its sources ("…and show me which files you used"). The citations tell you which folder to fix.
