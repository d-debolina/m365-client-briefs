# Fabrikam Medical – field sales playbook (fictional, for the NUDGE demo)

Upload this as a SharePoint page or file and add it to the agent as knowledge.

## Next-step rules by account stage
| Stage | Good next steps |
|---|---|
| Prospect | Book a 20-minute intro with the key surgeon · send the product overview · invite to a lunch & learn |
| Evaluation | Plan a **proctorship** with an experienced surgeon · book an in-service for the theatre team · prepare the value analysis pack |
| First cases | Cover the first three cases in person · ask the theatre manager for feedback after case 3 · log any issue the same day |
| Adopted | Quarterly business review · check stock levels · introduce a second product line |
| At risk | Call the key surgeon within 5 working days · ask what changed · involve your manager if a competitor is trialling |

## Timing rules
- **No contact for 30+ days** on an account in Evaluation or First cases → contacting the key surgeon is the top next step.
- After a **proctorship**: ask within 1 working day how it went, then plan the in-service within 2 weeks.
- After a **product evaluation**: if approved, book a value analysis meeting; if rejected, log the reason and schedule a check-in after 90 days.
- After **sample delivery**: check after 3 working days that the surgeon has tried them.

## What a good follow-up answer contains
- What happened (one sentence)
- Who was there
- What the customer asked for
- The next date, if any
