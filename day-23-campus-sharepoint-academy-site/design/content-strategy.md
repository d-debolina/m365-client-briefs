# CAMPUS content strategy

## Structure (one communication site, no subsites)
- **Home**: what's new, upcoming sessions (Events), learning paths (Quick links by level)
- **Courses** page per course (page template): outcome, modules, assets (Highlighted content filtered by Course), trainer
- **Course Materials** library: metadata, not folders: Course, Module, AssetType, Level, Language, Owner, ReviewBy, Status
- **Trainer Drafts** library: unique permissions (trainers only); approval flow moves Published items to Course Materials
- **Recordings**: Stream (on SharePoint) videos with chapters + transcripts

## Rules
1. One asset = one file in one place; pages link or roll up, never copy.
2. Every asset has an Owner and ReviewBy date; a monthly view shows "review due".
3. Retired assets are labelled (retention label "Academy retired – keep 2 years"), not deleted.
4. Guests only via a dedicated group + sharing policy; access reviews every quarter.

## Governance calendar
| When | What |
|---|---|
| Weekly | New content approval (Trainer Drafts → Course Materials) |
| Monthly | "Review due" view; broken-link check; site usage |
| Quarterly | Guest access review; permissions report; retire old courses |
| Yearly | Course catalogue refresh; analytics review with HR/L&D |
