# Handoff pack checklist (BATON)

- [ ] **Read me first** (1 page): what it does, who owns it, where things live
- [ ] Implementation spec (this repo's `spec/`), updated to "as built"
- [ ] Data model diagram + table/column list (generated from the solution)
- [ ] Security matrix + who is in which role today
- [ ] Environment map: Dev / Test / Prod URLs, environment variables and their values per stage (no secrets)
- [ ] Connection references and the service account that owns them
- [ ] Test matrix with last run results + how to re-run (Test Engine, flow tests)
- [ ] Solution checker report: zero critical issues, known warnings explained
- [ ] Runbook: deploy, roll back, rotate secrets, add a new location/category
- [ ] Known limitations + backlog (with the client's priorities)
- [ ] Recorded 20-minute walkthrough
