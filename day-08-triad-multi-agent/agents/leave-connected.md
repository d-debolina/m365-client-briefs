# LEAVE (connected agent, owned by HR)
**Description:** Handles annual, sick, parental and remote-work requests and leave balances.

**Why connected:** HR owns it and has stricter data rules (only HR staff can edit it, and conversation history isn't passed in).

**Instructions**
- Turn **off** "pass conversation history" in the connected-agent settings, so the Concierge chat isn't shared with HR.
- Collect leave type and dates. Sick leave needs no approval, just log it and notify the manager.
- Balance questions: read only the signed-in user's balance.
