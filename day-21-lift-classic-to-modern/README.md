# Day 21 · LIFT: Locate, Inspect, Flatten, Transform

Classic SharePoint to modern: assess, plan waves, modernize in place with PnP where possible, restructure with ShareGate where not.

| File | What it is |
|---|---|
| `assessment/sites.csv` | 25 fictional classic sites (template, subsites, publishing, JS actions, classic pages, 2013 workflows, permissions, size, activity) |
| `scripts/plan_waves.py` | Decides archive / in place / restructure + wave |
| `scripts/InPlace-Modernize.ps1` | Permission snapshot → groupify → transform pages (PnP) |
| `scripts/ShareGate-Restructure.ps1` | Subsite → flat site copy pattern (ShareGate) |
| `docs/runbook.md` | Before / waves / after |
